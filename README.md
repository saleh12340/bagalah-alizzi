# بقالة العزي للمواد الغذائية — المشروع النظيف الجديد

هذه النسخة هي إعادة بناء نظيفة للمشروع اعتماداً على المتطلبات المتراكمة للمشروع الأول، مع الحفاظ على هوية بقالة العزي والوظائف الأساسية المطلوبة وعدم إبقاء شاشات التطوير القديمة داخل النسخة الجديدة.

## البنية
- Android أصلي خفيف يعمل كغلاف WebView.
- الواجهة الأساسية HTML/CSS/JavaScript محلية، RTL وملائمة للشاشات الصغيرة.
- حفظ محلي دائم داخل التطبيق.
- جسر Android للطباعة، PDF، المشاركة، الاتصال وواتساب.
- GitHub Actions يبني APK Release مباشرة بواسطة Gradle.

## الوظائف الحالية
- الرئيسية والإحصاءات اليومية.
- فواتير البيع: إنشاء، تعديل، حذف، حفظ، طباعة، PDF، عميل نقدي أو آجل.
- إدخال الفاتورة بالترتيب: الإجمالي، الكمية، اسم الصنف، وسعر الوحدة محسوب تلقائياً.
- منع تكرار البند نفسه داخل الفاتورة بدمج الكمية والإجمالي.
- حساب المدفوع والمتبقي.
- العملاء: إضافة، تعديل، حذف الحساب، بحث، فتح الحساب من كامل الصف، رصيد، دفعات، حذف الدفعة، كشف الحساب، اتصال وواتساب، مشاركة PDF.
- الأصناف والمخزون: إضافة، تعديل، حذف، كمية، حد أدنى، سعر، تنبيه المخزون المنخفض.
- المشتريات: تسجيل فاتورة شراء وتحديث المخزون، حذف الفاتورة.
- الموردون: إضافة، تعديل، حذف.
- المصروفات: إضافة وحذف.
- الملاحظات: إضافة وحذف.
- التقارير: اليوم، أمس، 7 أيام، الشهر، السنة، الكل، وفترة مخصصة؛ مبيعات، فواتير، مصروفات، مشتريات، مدفوعات العملاء، الآجل، صافي الحركة وتنبيهات المخزون.
- الإعدادات: اسم المحل ورقم الجوال، النسخ الاحتياطي JSON والاستعادة، معلومات الطباعة والمشاركة، إعادة ضبط البيانات.
- تاريخ ووقت العمليات، مع عرض التاريخ الهجري عند الحاجة في طبقة JavaScript.
- معالجة لوحة المفاتيح والـ viewport حتى لا تغطي لوحة المفاتيح الحقول أو الأزرار.

## البيانات
بيانات التطبيق الجديدة تبدأ محلياً بدون بيانات تجريبية. النسخة الاحتياطية JSON يمكن تصديرها ومشاركتها ثم استعادتها من الإعدادات.

> ملاحظة مهمة: بيانات التشغيل التي كانت مخزنة داخل النسخ القديمة من التطبيق لا تُدمج تلقائياً في قاعدة التخزين الجديدة. ملفات المصدر القديمة بقيت ضمن تاريخ Git، بينما النسخة الحالية مصممة كنسخة نظيفة مستقلة.
