# بقالة العزي للمواد الغذائية — نسخة HTML داخل تطبيق Android أصلي

هذه النسخة تعيد بناء التطبيق من الصفر كصفحة HTML/CSS/JavaScript محلية تعمل داخل WebView أصلي.

## المزايا
- واجهة عربية RTL مستقرة ومهيأة للهواتف.
- لوحة رئيسية، فواتير، العملاء، المخزون، المصروفات، التقارير والإعدادات.
- تخزين محلي دائم عبر localStorage داخل WebView.
- إدخال فاتورة سريع: الإجمالي، الكمية، اسم الصنف، وسعر الوحدة محسوب تلقائياً.
- حساب أرصدة العملاء والمدفوعات وسجل العمليات.
- إضافة/تعديل/حذف الفواتير والعملاء والأصناف والمصروفات.
- مشاركة وطباعة الفواتير عبر الجسر الأصلي Android.
- نسخة احتياطية JSON قابلة للمشاركة.
- اتصال بالهاتف وواتساب من حساب العميل.
- معالجة خاصة للكيبورد والـ viewport وعدم تغطية الأزرار للبيانات.
- أيقونة التطبيق تحمل هوية بقالة العزي.

## البناء
GitHub Actions يبني APK Release مباشرة بواسطة Gradle بعد Expo Prebuild، بدون EAS أو EXPO_TOKEN.
